# 1画面だけのログイン練習サンプル

React + Vite + TypeScriptの初心者向けサンプルです。
ID・パスワードの入力、ログイン結果、ログアウトを、すべて同じ画面に表示します。
画面遷移はありません。再読み込みするとログアウト状態に戻ります。

## すぐに試す

`sample.html` をブラウザーで開きます。インストールやサーバーは不要です。

1. IDに `user`、パスワードに `pass` を入力します。
2. 「ログイン」を押すと、同じ画面に成功メッセージが表示されます。
3. 「ログアウト」を押すと、入力し直せます。

間違ったID・パスワードではエラーを表示します。空欄では送信できません。

## ソースコードを読む順番

まずは `src/main.tsx` だけを読んでください。画面と動作がこの1ファイルにあります。

1. `useState`：入力したID、パスワード、ログイン状態、エラーを覚えます。
2. `login`：入力内容を調べ、ログイン状態を変更します。
3. `logout`：状態と入力内容を元に戻します。
4. `return`：画面の内容です。`onChange`で入力を覚え、`onSubmit`でログイン処理を呼びます。

`{loggedIn ? A : B}` は、ログイン中ならA、それ以外ならBを表示する書き方です。
`{error && ...}` は、エラーがあるときだけ内容を表示する書き方です。
`FormEvent<HTMLFormElement>` は、フォーム送信のイベントを表すTypeScriptの型です。

その他のファイルの役割：

- `src/style.css`：色や余白などの見た目。
- `index.html`：Reactの表示先になる `root` を用意します。
- `package.json`：必要なライブラリと起動コマンド。
- `tsconfig.json`：TypeScriptの設定。最初は変更不要です。
- `scripts/standalone.mjs`：配布用HTMLを作る補助ファイル。最初は読む必要はありません。

Reactは画面を作り、TypeScriptはコードの型を確認し、Viteは開発用サーバーの起動と配布用ファイルの生成を担当します。

## 編集しながら試す

Node.js 22.12以降の対応LTSを使い、このフォルダーで実行します。

```sh
npm install
npm run dev
```

表示されたURLを開いて、`src/main.tsx` を編集してください。保存するとブラウザーに反映されます。
`sample.html` は生成済みのファイルなので、ソースの編集は自動反映されません。

## 配布用ファイルの再生成

```sh
npm run build:standalone
```

`dist` と `sample.html` が更新されます。

このサンプルは学習用のデモ認証です。本番のログイン機能にはサーバー側の認証が必要です。
